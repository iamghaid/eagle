How to Connect with Your Main Website

After adding packages here, click Export packages.json. Place the file in the same folder as your index.html. Then add this script to your main site just before </body>: 

fetch('packages.json')
  .then(r => r.json())
  .then(data => {
    // data.packages = your packages array
    renderPackages(data.packages);
  });
